# Jeel 1 Quran Academy — WordPress launch package

A free-first WordPress build package for **Jeel1.com**. It is designed for Astra Free + Elementor Free, Tutor LMS Free, WooCommerce, Fluent Forms, WP Mail SMTP, Tawk.to, and the relevant payment gateway plugins.

## Included

- `jeel1-homepage-free.json` — Elementor template importable from **Templates → Saved Templates → Import Templates**.
- `jeel1-kit.json` — Elementor Kit-style package containing global colors, Tajawal typography, RTL defaults, and the homepage template.
- `woocommerce-products.csv` — three virtual monthly plans ready for WooCommerce’s product importer.
- `assets/jeel1-logo.svg` — transparent-background gold/green logo artwork.
- `assets/jeel1-hero.svg` — lightweight hero illustration placeholder that can be replaced with a real family-approved photo.
- `assets/jeel1-pattern.svg` — subtle grid background.
- `SETUP.md` — one-time Hostinger/WordPress setup and integration instructions.

## Important free-plan notes

This package contains no Elementor Pro widgets, custom paid theme code, or paid plugins. Payment providers, Gmail SMTP, and Tawk.to still require their own free accounts/API credentials and approval. Paymob availability and supported methods depend on the merchant account and the current Paymob plugin; configure Vodafone Cash, Fawry, InstaPay, and PayPal/Stripe only after confirming gateway eligibility in Egypt/GCC.

The supplied homepage uses only Elementor Free-compatible Heading, Text Editor, Image, Button, Container, and Spacer widgets. Dynamic Tutor LMS dashboard data is configured in Tutor LMS after import rather than hard-coded into the public page.
